# Derek News — GitHub version

A single-file website: `index.html` is the whole site. No build step, no server code, no API key.

## Tabs
- **Home** — live Cicero weather strip, Time With God preview, quick links
- **Weather** — live current conditions + 7-day forecast for Cicero, NY (Open-Meteo, loaded fresh every time the page opens), plus TWC / NWS / SPC / Outage Map / Prepare links
- **Sports** — ready for stories; none added yet (DN Editorial was removed)
- **Faith** — Time With God prayer and Sunday Mass link
- **Christmas** — live countdown to December 25 + checklist

## Put it on GitHub Pages
1. Create a GitHub repo and upload `index.html` (and this README if you want).
2. Repo **Settings → Pages → Build and deployment → Deploy from a branch**, pick your main branch, root folder.
3. GitHub gives you a public `*.github.io` link — the weather updates itself on that link because it loads live in the visitor's browser.

## Updates
Ask Muse to change anything — new sports stories, a new prayer, Christmas additions — and the updated `index.html` can be pushed/uploaded to the repo to go live.
